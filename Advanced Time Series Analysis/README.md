The project provides an analysis of a time series data of gross domestic product (GDP) of the Norway. It contains the exploration of data patterns and trends, model implementation, and forecasting. Particularly, we conduct an economic time series model with macroeconomic variables. The components of GDP such as consumption (CS), export (EX), and gross fixed capital formation (IN) are added for multivariate time series analysis. Later, the forecast of GDP is performed for further economic decision-making. 

### Programming language: R
### Data frame:  Norway GDP on billion US$ in period 1978-2020
