This project provides an analysis of a time series data of gross domestic product (GDP) of the Norway. It contains the exploration of data patterns and trends, model implementation, and forecasting. Particularly, an economic time series model with macroeconomic variables is conducted. The components of GDP such as consumption (CS), export (EX), and gross fixed capital formation (IN) are added for multivariate time series analysis. Later, the forecast of GDP is performed for further economic decision-making.
